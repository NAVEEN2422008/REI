# REI — Fan Media Page

A simple static fan page for the artist "REI", embedding a music video and audio tracks with basic styling.

## Features
- Centered REI branding/title with custom styling.
- Embedded MP4 music-video player (autoplay).
- Audio player for multiple tracks.
- Minimal HTML + external stylesheet.

## Tech Stack
- HTML, CSS

## Project Structure
```
├── REI.html       # main fan page
├── my page.html   # secondary personal page
├── style.css      # shared styling
├── REI ... .mp4   # video
└── *.mp3          # audio tracks
```

## Installation
- No setup required; open the HTML files directly in a browser.

## Usage
1. Open `REI.html` in a browser.
2. The video and audio players load the bundled media.
3. (Asset filenames are referenced as-is; keep them in the same directory.)
